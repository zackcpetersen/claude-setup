# claude-setup

Personal Claude Code setup, portable to any machine: slash commands (`/pr`, `/babysit-pr`, `/self-review`, `/start-ticket`), output styles (Direct, Momentum, TLDR), helper scripts (`query_db`, `worktree`), a generic user-level `CLAUDE.md` with my preferences, and a repo manifesto template ([claude-md/MANIFESTO.md](claude-md/MANIFESTO.md) — "The Ten Laws", a design-philosophy doc to drop into any repo where agents write code).

Everything is generic - machine- and employer-specific values are marked `FILL IN`.

**To set up a new machine, follow [SETUP.md](SETUP.md).**
