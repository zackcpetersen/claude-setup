# claude-setup

Personal Claude Code setup, portable to any machine: slash commands (`/pr`, `/babysit-pr`, `/self-review`, `/start-ticket`), output styles (Direct, Momentum, TLDR), helper scripts (`query_db`, `worktree`), and a generic user-level `CLAUDE.md` with my preferences.

Everything is generic - machine- and employer-specific values are marked `FILL IN`.

**To set up a new machine, follow [SETUP.md](SETUP.md).**
